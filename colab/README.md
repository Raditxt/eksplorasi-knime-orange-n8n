# Kompatibilitas dengan Google Colab

🚧 Sedang dikerjakan.

Rencana isi:

1. **Orange di Colab.** Orange juga merupakan library Python (`pip install orange3`), jadi workflow Orange (Tree, undersampling, SMOTE-NC) bisa ditulis ulang sebagai notebook lalu hasilnya dibandingkan dengan versi GUI.
2. **KNIME dan Colab.** KNIME tidak bisa dijalankan di Colab. Yang diuji adalah cara keduanya bertukar data dan model (CSV, PMML/ONNX), serta versi notebook dari workflow KNIME menggunakan pandas dan scikit-learn.
